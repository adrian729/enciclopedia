Sources:
- A (FIB, Bachelor's in Informatics Engineering): https://www.fib.upc.edu/en/bachelors/bachelor-degree-informatics-engineering/curriculum/syllabus/A
- PAA (FIB, Grado en Ciencia e Ingeniería de Datos): https://www.fib.upc.edu/es/grados/grado-en-ciencia-e-ingenieria-de-datos/plan-de-estudios/asignaturas/PAA-GIA
- AA (FIB, Bachelor's in Informatics Engineering): https://www.fib.upc.edu/en/bachelors/bachelor-degree-informatics-engineering/curriculum/syllabus/AA#cont-1303

Course order: **A → PAA → AA**. A is the common foundational course (explicit prerequisite for AA). Between PAA and AA, the book content settles it: PAA's own books (Sipser, Cases/Màrquez, Hopcroft/Motwani/Ullman) are classic theory-of-computation/automata texts — standard foundational material, typically read before specialized topics — while AA's books (approximation algorithms, fixed-parameter algorithms, algorithmic game theory) are advanced/research-adjacent specializations. So PAA sits between A and AA.

Each section lists only books not already listed for an earlier course; where a course's page also cites an earlier course's book, that's noted as a cross-reference instead of repeating the full citation. Within each section, books are sorted in a suggested reading order (foundational first, advanced/specialized last).
